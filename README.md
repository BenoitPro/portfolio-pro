## Builds concrets

### SafeGPT
Extension Chrome open source qui anonymise les prompts en local avant qu'ils ne quittent le navigateur. Conçue pour les entreprises qui veulent utiliser l'IA générative sans risquer de Shadow AI sur des données sensibles.
- Stack : JavaScript, Regex, Chrome Extensions API
- Roadmap : SLM en local
- [Chrome Web Store](https://chromewebstore.google.com/detail/safegpt/cokleemccppaigbeofpnpdjknemehjkc) · [GitHub](https://github.com/IamAttila/SafeGPT---Anonymisation-Locale-pour-ChatGPT)
- Contexte : 91 % des entreprises FR touchées par le Shadow AI (Red Hat, nov. 2025)

- 156 réactions sur le retex LinkedIn

### Agence alAin

### Hermes

## Stack du site (méta)

- Next.js 14 (App Router) + TypeScript strict
- Tailwind CSS + shadcn/ui
- Framer Motion (animations)
- Lucide React (icônes)
- Knowledge Graph SVG custom (simulation physique maison)
- Hébergé sur Vercel, déploiement auto sur push `main`

### Développement local

```bash
npm install
npm run dev
```

Le site tourne sur http://localhost:3000.

### Source de vérité

Tout le contenu vient de `data/portfolio.ts`. Pour modifier un mot, c'est là.
Conventions design (couleurs, typo, animations) dans `design-tokens.md`.

### Easter eggs

- `⌘K` (ou `Ctrl+K`) ouvre la command palette
- Console DevTools affiche une signature au load
- Le knowledge graph est interactif — clique un node : section qui scroll ou popup contextuelle (concepts en blanc)

## Architecture du repo

```
app/             # Next.js App Router (layout, page, schema, robots, sitemap)
components/
  graph/         # KnowledgeGraph, MiniMap
  motion/        # Wrappers Framer Motion
  sections/      # Sections de la page (Hero, WhyMe, Projects, etc.)
  ui/            # Primitives shadcn + maison (GlassCard, ConceptPopup, etc.)
data/            # portfolio.ts (source de vérité unique)
lib/             # utils (cn), graph-physics
```
